# 端口配置说明

为了避免端口冲突，项目已配置为使用不同的端口：

| 项目 | 端口 | 说明 |
|------|------|------|
| 另一个项目 | 8000 | WSL中运行的服务 |
| **Spider_XHS (本项目)** | **8300** | FastAPI服务 |

## C#客户端配置

### 默认配置

C#客户端已默认配置为8300端口：

```csharp
// 使用默认端口8300
var client = new XHSApiClient();

// 或明确指定
var client = new XHSApiClient("http://localhost:8300");
```

### 自定义端口

如需使用其他端口，可以：

1. **修改服务端口** (fastapi_app/main.py):
```python
uvicorn.run(
    app,
    host="0.0.0.0",
    port=8400,  # 改为其他端口
    log_level="info"
)
```

2. **修改客户端连接**:
```csharp
var client = new XHSApiClient("http://localhost:8400");
```

## 端口冲突检查

### 检查端口是否被占用

```bash
# Windows
netstat -ano | findstr :8300

# Linux/Mac
lsof -i :8300
```

### 查看占用端口的进程

```bash
# Windows (需要管理员权限)
netstat -ano | findstr :8300
tasklist | findstr <PID>

# Linux/Mac
lsof -i :8300
```

### 结束占用端口的进程

```bash
# Windows
taskkill /F /PID <PID>

# Linux/Mac
kill -9 <PID>
```

## WSL端口转发

如果服务运行在WSL中，需要配置端口转发：

### 添加端口转发（管理员权限）

```powershell
# 获取WSL IP地址
wsl -e bash -c "ip addr show eth0 | grep 'inet ' | awk '{print `$2}' | cut -d/ -f1"

# 添加端口转发（假设WSL IP为172.23.1.9）
netsh interface portproxy add v4tov4 listenaddress=0.0.0.0 listenport=8300 connectaddress=172.23.1.9 connectport=8300

# 添加防火墙规则
netsh advfirewall firewall add rule name="XHS FastAPI 8300" dir=in action=allow protocol=tcp localport=8300
```

### 查看端口转发规则

```powershell
netsh interface portproxy show all
```

### 删除端口转发规则

```powershell
netsh interface portproxy delete v4tov4 listenaddress=0.0.0.0 listenport=8300
netsh advfirewall firewall delete rule name="XHS FastAPI 8300"
```

## 常见问题

### Q1: 端口被占用怎么办？

**解决方案**:
1. 检查是否已启动服务
2. 结束占用端口的进程
3. 或修改为其他端口

### Q2: 无法访问服务？

**检查清单**:
- [ ] 服务是否已启动
- [ ] 端口是否正确（8300）
- [ ] 防火墙是否允许该端口
- [ ] 是否配置了WSL端口转发（如果使用WSL）

### Q3: WSL中服务无法从Windows访问？

**解决方案**:
1. 确保服务监听0.0.0.0而不是127.0.0.1
2. 配置Windows端口转发
3. 检查WSL IP地址是否变化

### Q4: 局域网其他设备无法访问？

**解决方案**:
1. 配置Windows端口转发（监听0.0.0.0）
2. 添加防火墙入站规则
3. 确保服务设备防火墙允许该端口

## 生产环境部署

### 使用不同端口

生产环境建议使用标准HTTP端口（80）或HTTPS端口（443）：

```python
# HTTP
uvicorn.run(app, host="0.0.0.0", port=80)

# HTTPS (需要SSL证书)
uvicorn.run(app, host="0.0.0.0", port=443, ssl_keyfile="key.pem", ssl_certfile="cert.pem")
```

### 使用Nginx反向代理

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://localhost:8300;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
